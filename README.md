# نظام أكاديمية الذكاء الاصطناعي الدولية

نظام ويب لإدارة الأكاديمية: الطلاب، الدورات وأيامها، التسجيل والرسوم بالريال السعودي والريال اليمني، تحضير الحضور والغياب، المنتجات والمبيعات، مع تصدير الكشوفات PDF وExcel.
يعمل كتطبيق ويب ويمكن تثبيته على الجوال (إضافة إلى الشاشة الرئيسية).

> **الدليل المرجعي الشامل للنظام (البنية، قاعدة البيانات، الصلاحيات، التعديل، النقل، التسليم لمبرمج): [docs/SYSTEM.md](docs/SYSTEM.md)**

الرابط: https://intai-academy.web.app

- قاعدة البيانات وتسجيل الدخول: **Firebase** (Firestore + Authentication) على الخطة المجانية **Spark**.
- الاستضافة: **Firebase Hosting** برابط `‎.web.app`.
- لا يوجد خادم ولا Cloud Functions ولا أي خدمة مدفوعة.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| الإدارة | كل شيء، وإضافة المستخدمين وإيقافهم، والإعدادات |
| نائب المدير | كل البيانات والإعدادات والحذف، دون إدارة المستخدمين |
| مسؤول التسجيل | الطلاب، إنشاء وتعديل الدورات، التسجيل والمدفوعات، الحضور، المنتجات |
| السكرتير | الطلاب، التسجيل والمدفوعات، الحضور، البيع |
| المدرب | دوراته فقط: أسماء الطلاب وتحضير الحضور والغياب (لا يرى أي بيانات مالية) |

الطلاب ليس لهم دخول للنظام؛ هم سجلات في قاعدة البيانات فقط. الصلاحيات مطبقة في قواعد قاعدة البيانات `firestore.rules` وليس في الواجهة فقط.

## الربط بمشروع Firebase الخاص بالأكاديمية (مرة واحدة)

1. ادخل [Firebase Console](https://console.firebase.google.com) بحساب الأكاديمية وأنشئ مشروعا جديدا (الخطة المجانية Spark تكفي).
2. **Build > Authentication > Get started > Sign-in method**: فعّل **Email/Password**.
3. **Build > Firestore Database > Create database**: اختر موقعا قريبا (مثل `europe-west` أو `me-central`) وابدأ بـ Production mode.
4. **Project settings > General > Your apps**: أضف تطبيق ويب (Web `</>`)، وانسخ قيم `firebaseConfig` إلى الملف `src/lib/firebaseConfig.ts`.
5. ضع معرف المشروع (Project ID) في الملف `.firebaserc` مكان `YOUR_FIREBASE_PROJECT_ID`.

## النشر

```bash
npm install
npm install -g firebase-tools
firebase login
npm run deploy
```

الأمر `npm run deploy` يبني التطبيق وينشر الموقع وقواعد الحماية معا. بعدها يعمل على:
`https://PROJECT_ID.web.app`

## أول تشغيل

عند فتح الرابط أول مرة تظهر شاشة **"الإعداد الأول"** لإنشاء حساب الإدارة الرئيسي (الاسم، اسم المستخدم، كلمة المرور).
بعدها تُضاف حسابات الموظفين من صفحة **المستخدمون**، وترسل لكل موظف اسم المستخدم وكلمة المرور.

ملاحظات الحسابات (قيود الخطة المجانية بدون خادم):
- الموظف يغير كلمة مروره بنفسه من صفحة **حسابي**.
- إذا نسي موظف كلمة المرور: أوقف حسابه من صفحة المستخدمين وأنشئ له حسابا جديدا باسم مستخدم آخر.
  (أو من Firebase Console > Authentication يمكن حذف الحساب ثم إعادة إنشائه بنفس الاسم).

## التطوير والتجربة محليا

```bash
npm install
firebase emulators:start --only auth,firestore --project demo-intai
VITE_EMULATOR=1 npm run dev
```

ثم افتح `http://localhost:3000`. وضع `VITE_EMULATOR=1` يعمل على قاعدة بيانات تجريبية محلية لا تمس البيانات الحقيقية.

## هيكل المشروع

```
src/
  lib/          اتصال Firebase، الأنواع، الصلاحيات، العمليات، التصدير PDF/Excel
  views/        الصفحات: الرئيسية، الطلاب، الدورات، تفاصيل الدورة، المنتجات، المستخدمون، الإعدادات، حسابي
  ui.tsx        مكونات الواجهة
public/         الشعار وأيقونات التطبيق وملفات التثبيت على الجوال
firestore.rules قواعد الحماية والصلاحيات
```

## البيانات في Firestore

| المجموعة | المحتوى |
|---|---|
| `users` | الموظفون وصلاحياتهم |
| `students` | بيانات الطلاب |
| `courses` | الدورات: المدرب، الأيام وتواريخها، السعر بالعملتين |
| `enrollments` | تسجيل طالب في دورة (يراه المدرب) |
| `accounts` | الرسوم والخصم والدفعات لكل تسجيل (لا يراه المدرب) |
| `attendance` | الحضور: مستند لكل يوم من أيام الدورة |
| `products` / `sales` | المنتجات والمبيعات |
| `settings` | اسم الأكاديمية وبيانات رأس الكشوفات وطرق الدفع |
